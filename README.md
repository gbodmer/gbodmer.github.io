# gbodmer.github.io

Personal website of Guy Bodmer, built with plain HTML and CSS and hosted on GitHub Pages.

Live at: https://guybodmer.com (also https://gbodmer.github.io)

## Editing

- `index.html` – the content (text, sections, projects)
- `style.css` – the design (colours, layout, fonts)

To preview locally, open `index.html` in a browser, or use the **Live Server** extension in VS Code.

To publish changes: commit and push to `main`. GitHub Pages updates the site within a minute or two.
